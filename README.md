# 🎃 万圣节 · ALL HALLOWS

一个万圣节主题介绍站点：从萨温节的篝火，到影院里的尖叫。

**技术栈**：React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion

## ✨ 内容板块

- **Hero**：月夜场景（星星 / 蝙蝠 / 飘雾 / 古宅剪影 / 会眨眼的南瓜灯）+ 10 月 31 日倒计时
- **起源与历史**：萨温节 → 罗马/基督教 → 爱尔兰移民 → 商业化（NRF 消费数据）
- **两千年时间线**：9 个关键节点，滚动生长的发光中轴
- **传统习俗**：不给糖就捣蛋、南瓜灯、变装、鬼屋、漂浮苹果、篝火
- **符号与角色**：女巫、幽灵、黑猫、蝙蝠、蜘蛛、骷髅、怪物三人组、满月稻草人
- **万圣节 Cinema**：8 部经典恐怖片的自绘 SVG 复古海报墙，点击弹窗播放预告片（YouTube 不可达时优雅降级为外链）

## 🕹️ 彩蛋

- 点击页面任意处 → 撒糖果（🍬🍭🎃🦇…偶尔冒出幽灵）
- Hero 糖果雨、南瓜灯眨眼、霓虹灯闪烁
- 滚动动效全套：视差星空、标题逐字弹入 / 四散、数字滚动计数、场景聚光、导航智能隐藏

## 🚀 运行

```bash
npm install
npm run dev      # http://localhost:5585
npm run build    # 生产构建
npm run preview  # 预览构建产物（同为 5585 端口）
```
